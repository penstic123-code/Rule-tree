# R1.1 钩子 🔨
上级：R1 规则记录与送达
- （AI 发现）hook 脚本会被复制到 ~/.ruletree/runtime/，由 Claude Code 直接调用，所以不能把 hooks 打包合并成一个文件。
- （AI 发现）改了 hooks/ 或 src/ 后，要在 VS Code 重新加载窗口（Reload Window），新脚本才会复制到 ~/.ruletree/runtime/ 生效；否则 hook 仍跑旧版。
- （AI 发现）改 hook 的速度前先实测各段耗时，别凭猜测判断原因（以前猜两次都错）。
