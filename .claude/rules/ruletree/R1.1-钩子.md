# R1.1 钩子 🔨
上级：R1 规则记录与送达
- （AI 发现）VS Code 路线：hook 脚本会被复制到 ~/.ruletree/runtime/，由 Claude Code 直接调用，所以不能把 hooks 打包合并成一个文件。Claude 应用插件路线不复制，hook 直接从插件根目录（hooks/hooks.json 里的 ${CLAUDE_PLUGIN_ROOT}）运行，同样不能打包。
- （AI 发现）VS Code 路线：改了 hooks/ 或 src/ 后，要重新加载窗口（Reload Window），新脚本才会复制到 ~/.ruletree/runtime/ 生效；否则 hook 仍跑旧版。插件路线读的就是插件文件夹，新开会话即生效。
- 决定：项目自己已经装了 hook（VS Code 路线 init 写进 settings 的）时，插件带的 hook 让路、不记，免得一次改动记两遍；插件路线的 init 只写允许规则，不装 hook、不复制运行时。
- （AI 发现）改 hook 的速度前先实测各段耗时，别凭猜测判断原因（以前猜两次都错）。
